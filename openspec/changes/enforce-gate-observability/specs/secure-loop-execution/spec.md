## MODIFIED Requirements

修改要求 / Chinese modification requirements

### Requirement: Unified fail-closed execution entry / 统一关闭失败执行入口
The engine SHALL expose one Gate Check service used by workflow stage execution, task run, client submission, and protected repository action entry points. It SHALL compute the engine-owned subject, check the union of stage and action gates, and refuse the operation before any task state transition, provider invocation, or protected side effect when a prerequisite is not satisfied.

引擎必须提供一个由 workflow 节点执行、task run、client submission 和受保护仓库动作入口共同使用的 Gate Check 服务。它必须计算引擎持有的 subject，检查节点门禁与动作门禁的并集，并在任一前置条件不满足时，于任务状态转换、provider 调用或受保护副作用之前拒绝操作。

#### Scenario: Client submission cannot bypass a gate / client submission 不能绕过门禁
- **WHEN** a client submits a protected task without a current GatePass
- **THEN** submission is blocked before verification transitions or evaluator acceptance are recorded
- **当** client 在没有当前 GatePass 时提交受保护任务
- **则** 提交在验证状态转换或 evaluator 接受记录前被阻断

#### Scenario: CLI and MCP share gate semantics / CLI 与 MCP 共享门禁语义
- **WHEN** equivalent protected operations arrive through CLI and MCP
- **THEN** both invoke the same Gate Check service and produce equivalent blocking evidence
- **当** 等价的受保护操作分别从 CLI 和 MCP 进入
- **则** 两者调用同一 Gate Check 服务并产生等价阻断证据

### Requirement: Timing and digest evidence are executable outputs / 计时与摘要证据必须是可执行输出
The execution result SHALL include the stage timing projection and the canonical subject/context/artifact digest metadata used for the decision. Digest values MUST identify their canonicalization and algorithm version and MUST be generated by the shared digest utility.

执行结果必须包含节点计时投影，以及决策使用的规范 subject/context/artifact 摘要元数据。摘要值必须标识规范化和算法版本，并必须由共享 digest 工具生成。

#### Scenario: Digest implementation is consistent / 摘要实现一致
- **WHEN** the same JSON subject is processed by a Gate, Provider adapter, and StandardPage artifact verifier
- **THEN** all components use the same canonical serialization and versioned SHA-256 digest contract
- **当** 同一个 JSON subject 被 Gate、Provider adapter 和标准页产物校验器处理
- **则** 所有组件使用同一稳定序列化和版本化 SHA-256 摘要契约
