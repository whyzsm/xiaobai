# Xiaobai Project Memory / 小白项目记忆

## 中文

这是 OpenHands 分发环境创建的空项目记忆。小白可以在有长期价值的工作完成后写入双语 checkpoint，并在写入后执行当日审计。

本目录属于接收方自己的 Obsidian Vault，不属于小白或小能 Git 仓库。

## English

This is an empty project memory initialized by the OpenHands distribution. After durable work, Xiaobai may write a bilingual checkpoint and run the same-day audit.

This directory belongs to the recipient's Obsidian vault, not to the Xiaobai or Xiaoneng Git repository.
