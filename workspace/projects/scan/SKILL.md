# scan Project Skill / scan 项目技能

## 中文

`scan` 是独立 T-MAX 业务项目，只挂载 `scan` 业务仓，并使用 `xiaoneng` 作为公共背景。修改前读取背景并检查目标仓的分支、工作区和已有改动；业务代码只落在 `scan`，默认只做本地修改和静态检查。

## English

`scan` is a standalone T-MAX business project. It mounts only the `scan` business repository and uses `xiaoneng` as its shared background. Read the background and inspect the repository's branch, worktree, and existing changes before editing; business code belongs only in `scan`, with local edits and static checks as the default.
