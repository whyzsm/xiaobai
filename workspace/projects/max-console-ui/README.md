# max-console-ui Mounted Project / max-console-ui 挂载项目

## 中文

独立 T-MAX 项目，公共背景为 `xiaoneng`，只挂载 `max-console-ui`。运行 `npm run mount:max-console-ui` 创建本机挂载。

## English

Standalone T-MAX project using `xiaoneng` as its shared background and mounting only `max-console-ui`. Run `npm run mount:max-console-ui` to create local mounts.
