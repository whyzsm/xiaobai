# max-console-ui Project Skill / max-console-ui 项目技能

## 中文

`max-console-ui` 是独立 T-MAX 业务项目，只挂载同名业务仓，并使用 `xiaoneng` 作为公共背景。修改前读取背景并检查目标仓分支、工作区和已有改动；业务代码只落在目标仓，默认不提交、不推送。

## English

`max-console-ui` is a standalone T-MAX business project. It mounts only the repository with the same name and uses `xiaoneng` as its shared background. Read the background and inspect branch, worktree, and existing changes before editing; business code belongs only in the target repository, with no automatic commit or push.
