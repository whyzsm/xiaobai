# operateSupport Mounted Project / operateSupport 挂载项目

## 中文

独立 T-MAX 项目，公共背景为 `xiaoneng`，只挂载 `operateSupport`。运行 `npm run mount:operateSupport` 创建本机挂载。

## English

Standalone T-MAX project using `xiaoneng` as its shared background and mounting only `operateSupport`. Run `npm run mount:operateSupport` to create local mounts.
