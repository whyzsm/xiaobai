# operateBusiness Mounted Project / operateBusiness 挂载项目

## 中文

独立 T-MAX 项目，公共背景为 `xiaoneng`，只挂载 `operateBusiness`。运行 `npm run mount:operateBusiness` 创建本机挂载。

## English

Standalone T-MAX project using `xiaoneng` as its shared background and mounting only `operateBusiness`. Run `npm run mount:operateBusiness` to create local mounts.
