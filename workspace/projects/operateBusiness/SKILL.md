# operateBusiness Project Skill / operateBusiness 项目技能

## 中文

`operateBusiness` 是独立 T-MAX 业务项目，只挂载同名业务仓，并使用 `xiaoneng` 作为公共背景。修改前读取背景并检查目标仓自己的分支、工作区和已有改动；业务代码只能落在目标仓，默认只做本地修改和静态检查。

## English

`operateBusiness` is a standalone T-MAX business project. It mounts only the repository with the same name and uses `xiaoneng` as its shared background. Read the background and inspect the target repository's branch, worktree, and existing changes before editing; business code belongs only in the target repository, with local edits and static checks as the default.
