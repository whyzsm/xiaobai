# KPIUI Project Skill / KPIUI 项目技能

## 中文

`KPIUI` 是独立 T-MAX 业务项目，只挂载 `KPIUI` 业务仓，并使用 `xiaoneng` 作为公共背景。修改前先读取背景并检查业务仓自己的分支和工作区；业务代码只能落在 `KPIUI`，默认只做本地修改、静态检查和状态说明，不自动提交或推送。

## English

`KPIUI` is a standalone T-MAX business project. It mounts only the `KPIUI` business repository and uses `xiaoneng` as its shared background. Read the background and inspect the repository's branch and worktree before editing; business code belongs only in `KPIUI`, with local edits, static checks, and status reporting as the default.
