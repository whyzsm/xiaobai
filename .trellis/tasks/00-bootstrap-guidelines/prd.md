### Goal

Turn the `.trellis/spec/frontend/` files generated by Trellis initialization from generic frontend templates into Xiaobai repository-level development guidelines. The directory is not deleted or renamed in this pass because the root `AGENTS.md` requires confirmation before create, delete, and batch operations. The Trellis-generated `frontend` directory name is kept for now, while its content is rewritten for the Xiaobai engineering repository.

### Scope

- Spec directory: `.trellis/spec/frontend/`
- Task file: `.trellis/tasks/00-bootstrap-guidelines/prd.md`
- Evidence sources: root `AGENTS.md`, root `SKILL.md`, `package.json`, `loop-engineering/docs/**`, runtime source, workspace configuration, OpenHands documentation, and test files.

This task does not modify `loop-engineering/` runtime code, does not handle the existing local control-plane changes, and does not stage, commit, or push.

### Acceptance Criteria
